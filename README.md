# kechess web

Play online at [kechess](https://lexaaakorolevv-cyber.github.io/kechess/).

This branch contains the deployed browser app. A local HTTP server can serve these files without a build step. To play with a friend, create a room and share its code or invitation link. Games and settings are stored in the browser.

The [Android APK](kechess-1.5.apk) and its [source archive](kechess-1.5-source.zip) are also available. Stockfish.js is distributed under the [GNU General Public License v3](stockfish-copying.txt). Its exact [corresponding source](stockfish-17.1-source.tar.gz) is included. See [vendor notices](vendor/) for the other third-party components.
